Keep the task moving / t

terminal · remote host · desktop
01 / On the go

Check in from anywhere.

Connect through a phone terminal or another computer, see your sessions with t ls, and pick up the conversation when you have a moment.

02 / Local to cloud

Take the work to another host.

Use t beam to move a session over SSH between your machine and a remote Mac or Linux host, including a cloud VM you set up. Bring it back when you return.

03 / Desktop

Switch how you work.

On a Mac, t app opens a local Codex conversation in the desktop app with its running web preview. Continue the same thread in the terminal when you are ready.

Make it yours / make it repeatable

Choose your defaults. Share your playbook.

Choose what works for you, and share the defaults your team or enterprise wants to standardize across vendors: models, MCP tools, and preferred workflows. t config sets agent, model, and effort defaults for new sessions, including agent choices per project. Each agent's own configuration controls which MCP tools load; t gives supported agents a common session workflow.
